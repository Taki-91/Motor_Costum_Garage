## Deskripsi Project

Project ini merupakan Mini Project 1 pada mata kuliah Pemrograman Web.

Project dibuat menggunakan PHP untuk mengelola dan menampilkan
informasi produk motor custom.

Informasi yang ditampilkan meliputi:

- ID Motor
- Nama Motor
- Kategori
- Harga
- Stok
- Status Stok
- Total Nilai Stok
- Deskripsi

## Struktur File

- `products.php` → menyimpan data motor custom.
- `functions.php` → berisi fungsi untuk proses perhitungan dan pengecekan stok.
- `index.php` → menampilkan data motor dalam bentuk tabel.
- `README.md` → dokumentasi project.

## Fitur

- Menampilkan daftar motor custom.
- Menghitung total nilai stok.
- Mengecek status stok.
- Menampilkan informasi motor dalam tabel.
